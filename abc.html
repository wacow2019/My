📋 建案核心四張資料表結構說明

以下結構與關聯邏輯解析自 ils.sql，專注於建案主表與其核心三大子表之欄位對應。

1. 建案主表：project_main

說明： 整個業務系統的最頂層母表，紀錄每一個廣告或建案項目的基本資訊。

欄位名稱 資料型態 鍵值屬性 用途說明
id int Primary Key 建案唯一自動遞增 ID（主鍵，供子表關聯）
name varchar - 建案/專案名稱（例如：藝舍創意大樓、A案）
code varchar - 建案內部編號 / 識別碼
status int / varchar - 建案狀態（例如：進行中、結案、暫停）
create_time datetime - 建案建立時間

2. 房屋/戶別主表：project_house

說明： 紀錄該建案底下所屬的所有個別房屋、樓層或戶別資料（例如：A1戶、B2戶）。

欄位名稱 資料型態 鍵值屬性 用途說明
id int Primary Key 房屋戶別唯一自動遞增 ID
project_id int Foreign Key 對應到 project_main.id（關聯建案）
house_name varchar - 房屋/戶別名稱（例如：3F-A1、5F-B2）
floor int / varchar - 該房屋所在的樓層
area_size decimal - 房屋坪數 / 面積

3. 建案設施設備表：house_facility

說明： 紀錄建案所擁有的公設、公共設施或公用設備項目（例如：大廳、健身房設備、電梯）。

欄位名稱 資料型態 鍵值屬性 用途說明
id int Primary Key 設施設備唯一自動遞增 ID
project_id int Foreign Key 對應到 project_main.id（關聯建案）
facility_name varchar - 公設或設備名稱（例如：頂樓空中花園、接待大廳沙發）
quantity int - 設施或設備數量
note text / varchar - 備註說明事項

4. 建案錯誤/遺失紀錄表：house_miss

說明： 紀錄建案在點交、巡檢或施工過程中，發現的遺失物、瑕疵、缺失或錯誤報修項目。

欄位名稱 資料型態 鍵值屬性 用途說明
id int Primary Key 缺失紀錄唯一自動遞增 ID
project_id int Foreign Key 對應到 project_main.id（關聯建案）
miss_title varchar - 缺失或遺失項目摘要（例如：2F走廊磁磚破裂、逃生指示燈遺失）
status int / varchar - 處理狀態（例如：未處理、改善中、已修復）
report_date date / datetime - 缺失回報或發現的日期
